# Capital Convert (demo) - notice

This project contains **no Bethesda game content**. It is a set of scripts that convert the Fallout 3 files on *your* PC for use with
*your* copy of Fallout 4. You need to own Fallout 3, Fallout 4 and the Fallout 4 Creation Kit. The converted result is for your personal
use only and must not be shared or uploaded.
