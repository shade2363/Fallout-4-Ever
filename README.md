# Fallout 4-Ever

**Walk the Capital Wasteland in Fallout 4.** A one-click converter that builds the Fallout 3 world inside your own copy of Fallout 4.
By TikTok@yourstruly_0, with opness1549.

> **Demo release.** This first release builds the **world, the actors and the navmesh**: the whole Capital Wasteland and the five DLC worlds,
> with NPCs and creatures placed where they stood in Fallout 3, and working navigation. Quests, dialogue, voice, audio, weather and
> NPC faces are **not** in the demo yet. See [docs/FAQ.md](docs/FAQ.md) for exactly what works.

## What you need
| | |
|---|---|
| **Fallout 3** | *Game of the Year Edition* with all five DLC (Steam, GOG or Epic) |
| **Fallout 4** | Steam, version 1.11.x, plus the free **Fallout 4 Creation Kit** (Steam, Tools) |
| **PC** | Windows 10 or 11 (64-bit), **150 GB free disk space**, 32 GB RAM recommended |
| **Time** | about **4 to 8 hours** the first time (the PC is busy; it runs by itself) |
| **Internet** | once, to download two free tools (about 136 MB); later only when you press *Check for updates* |

You must own the games. **No game files are included or shared**: everything is built on your PC from your own copies, for your personal use.

## Install in 4 steps
1. Download `CapitalConvert-x.y.z.zip` from the [Releases page](https://github.com/shade2363/Fallout-4-Ever/releases) and unzip it anywhere (not inside a game folder).
2. Close Fallout 3, Fallout 4 and the Creation Kit. Double-click **`CapitalConvert.exe`**.
3. Check the green panel (your games should be found automatically; use *Browse* if not), then click **INSTALL / RESUME**.
4. Wait. When it says **FINISHED**, start Fallout 4 from Steam, open the console with `~` at the main menu and type `coc MegatonPlaza`.

You can close the window at any time; press **INSTALL / RESUME** again and it carries on where it stopped.
Detailed steps with what to expect: [docs/INSTALL.md](docs/INSTALL.md).

## Updating and removing
* **Updates:** open the *Updates* button, press *Check for updates*. Updates are signed; only the steps whose scripts changed run again. See [docs/UPDATE.md](docs/UPDATE.md).
* **Remove it:** [docs/INSTALL.md](docs/INSTALL.md#uninstall) explains the uninstall, which removes exactly the files it installed and restores your settings.
* **Something went wrong?** [docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md).
